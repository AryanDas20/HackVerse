01 / GETTING STARTED

Your personal builder workspace

HackVerse is divided into dedicated sections. The top navigation takes you to a separate workspace for each job, instead of placing every feature on one long page.

1

Create your account

Use Google sign-in or your email and password. Email registration sends a verification email. Sign in before viewing opportunity listings, events, event details, messaging or member-only areas.

2

Complete your builder profile

Add your name, username, college, course, graduation year, city, introduction, skills, interests and preferred roles. Add GitHub, LinkedIn or portfolio links when you want people to review your work.

3

Choose your visibility

A discoverable profile appears in Community search. A private profile is excluded from the public directory and the public team matcher. Do not publish contact details unless you explicitly want other members to see them.

4

Take the guided tour

Use the ✧ tour button in the header or replay it from Settings. The tour changes sections, scrolls to each feature and explains its purpose. Use Next, Back or Exit at any time.

02 / OPPORTUNITIES

Find events worth building for

Explore contains hackathons, case competitions, coding events, bootcamps, courses and certifications collected from connected discovery sources.

Search and filter

Search by title, organiser, technology or skill. Filter by type, country, eligibility, region, online/in-person/hybrid format, track, source, experience level, cost and deadline. Sort by nearest deadline, newest, prize or title.

Save and verify

Save opportunities to your personal shortlist. Open a listing for its description, organiser, eligibility and official registration link. HackVerse is not the organiser, so confirm dates, fees and rules on the provider's official page.

Sign-in rule: Visitors who are signed out see a membership gate. Firestore rules also require authentication to read opportunity documents.

03 / COMMUNITY + TEAMS

Find collaborators, not just contacts

Community directory

Search public builder profiles by name, username, college, skills, role interests and other public profile information. Open a profile to review its skills, bio and portfolio links. Start a direct chat from a profile or report an account that violates community rules.

AI-assisted Smart Team Builder

Enter the project name and brief, team size, number of teams, target roles/skills, college or year preference and collaboration mode. Balanced matching spreads skill coverage across teams; best-fit mode ranks candidates by their profile match. You can deselect suggestions before creating group chats. Scores are estimates, not guarantees.

04 / MESSAGING

A collaboration-first chat system

The messaging workspace is designed around familiar modern messenger patterns. It is a HackVerse implementation, not an official WhatsApp client or an exact copy of WhatsApp.

Conversation inbox

Switch between All, Unread, Groups and Archived. Search chat names and previews. Pin a chat or archive it from Chat options. Open a person from Community to start a direct conversation, or create a project group with selected builders.

CHATSALL · UNREAD · GROUPS

Messages and collaboration

  • Reply to a specific message with a quoted preview.
  • React using emoji and see reaction counts.
  • Copy, forward or star important messages.
  • Edit your own text and delete your own messages within the current edit window.
  • Share images, videos, audio and common documents up to 15 MB.
  • Record and send a short voice note using your microphone.
  • See when another participant is typing and when a conversation has been read.

Groups and moderation

Group owners and admins can review members, add discoverable builders and remove members. Group creation asks you to confirm that selected members have agreed to join. Group membership and message access are enforced by Firestore rules.

What is not enabled yet

There is no end-to-end encryption protocol, voice/video calling, disappearing messages, cloud backup, full-device push delivery or multi-device message sync equivalent to WhatsApp. Pinned/archived/starred chat preferences currently live in this browser. Add these capabilities through dedicated backend services before making a commercial claim of WhatsApp parity.

05 / HACKVERSE AI + AI WISH

Ask the assistant to help you work

Website Help

Ask how a feature works, where a control is, how to complete your profile, how to find opportunities or how to use the team builder. The assistant uses the HackVerse feature guide and current page context.

AI Wish / action planner

Describe a task in plain language. Agent37 prepares supported actions such as opening sections, searching opportunities, saving or opening a listing, searching builders and creating a project. Review the list, then press Apply. The browser validates action data and Firebase permissions still apply.

AI does not have unrestricted access to all records. It cannot silently send messages, delete data, change administrator permissions or submit forms to external websites.

Private AI history

Sign in to save conversations. Each AI history item belongs to its Firebase user ID. Agent37 session identifiers are held by the server-side integration so a chat can continue the right agent session.

Agent37 requirements

The instance ID identifies the agent; it does not authenticate API requests. The server-only Agent37 API key and Firebase service account must be configured in Vercel. Never put them in browser JavaScript, GitHub or screenshots.

06 / PROFILE + PROJECTS

Turn your profile into a builder portfolio

My Profile displays your builder identity, skills, interested roles, college and links. The Project Showcase stores projects you have created, with a public/private visibility setting. Create a project with a clear title, problem statement, tech stack, live demo and repository link. Review all URLs before publishing.

07 / ACTIVITY + SETTINGS

Stay organised and tune your workspace

Activity centre

Shows unread conversation activity, recent conversations and reminders for saved opportunities with registration deadlines in the next 14 days. The bell displays the combined alert count. Click an item to open its chat or opportunity. Browser notifications can be enabled while the app is open and browser permission is granted; this release does not include background push notifications after the browser is closed.

Settings

Change dark/light theme, motion intensity, text size, in-app activity, desktop notifications, opportunity reminders and sound preference. Profile visibility is stored with your public Firebase profile. Other interface preferences are saved in the current browser.

08 / DEPLOYMENT CHECKLIST

Before inviting your community

Keep your existing real public/firebase-config.js and confirm its Firebase project ID. Chat media uses Supabase, not a Firebase Storage bucket.
Deploy the updated Firestore rules and indexes after merging any production-specific collections and indexes.
Create a private Supabase chat-media bucket, set its 15 MB limit, and add the public project URL/key plus the server-only service key before testing uploads.
Deploy to Vercel from the project root so /api/agent37/chat runs as a serverless endpoint.
Set Agent37 credentials and Firebase Admin service account as server-only Vercel environment variables, then redeploy.
Test with at least two real accounts: direct messages, group chat, read receipts, attachments, privacy, event access and AI conversation isolation.
Important: do not claim end-to-end encryption or exact WhatsApp parity. The upgraded app includes common messenger features, but it does not yet implement WhatsApp's cryptographic protocol, calling, disappearing messages or all device-sync behaviours.
