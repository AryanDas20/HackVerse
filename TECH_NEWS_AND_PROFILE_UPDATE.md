# HackVerse feature update

## Tech News
- Added `/news` route and navigation tab.
- Fetches top/latest stories from the public Hacker News API.
- Provides AI, Developer, Security, Saved categories, keyword search, sorting, refresh and load-more.
- Stories can be opened, saved in browser local storage and shared through native share or copied link.

## Opportunity sharing cards
- Opportunity share modal now includes a branded HackVerse opportunity card preview with title, summary, selected details and source URL.
- Share options continue to support WhatsApp, native share, HackVerse chat and copy link.

## Profile visibility
- Profile editor now uses Public and Private only.
- Removed Followers-only and the separate Builders-directory consent checkbox from profile editing.
- Public visibility publishes profiles in the Builders directory after required name/username validation; Private removes the public directory projection.
- Contact visibility remains independently configurable.
