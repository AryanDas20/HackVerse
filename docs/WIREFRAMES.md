# Screen Wireframes (structure)

1. Landing: top nav → value proposition → global search → source strip → featured opportunities → benefits → CTA.
2. Discover: sticky search → track/mode/deadline filters → sort → cards/list/map/calendar switch → pagination.
3. Event detail: title/status/source badges → register CTA → deadline timer → overview → eligibility/rules → prizes → timeline → source attribution → report action → find team.
4. Saved/deadlines: calendar/timeline → saved event cards → reminder controls → preparation checklist.
5. Team marketplace: skill/availability filters → teammate cards → team listings → request/invite → report/block.
6. Profile: builder headline → skills → timezone/availability → GitHub/portfolio → past events → projects/wins → privacy controls.
7. Project page: pitch → demo/repo → screenshots → team → hackathon → awards → likes/comments.
8. Social feed: source chips → post summary → original post link → linked official event → verification state.
9. Organizer: event creation/import → details/rules/prizes → participants/teams → announcements → submissions → judging → export.
10. Judge: assigned events → rubric → submission review → score/comments → conflict declaration.
11. Admin: moderation queue → candidate evidence → duplicate candidates → approve/reject/edit/flag → audit trail.
12. Notifications/settings: preference matrix → connected accounts → privacy/export/delete → session controls.
