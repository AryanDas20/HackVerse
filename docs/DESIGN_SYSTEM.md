# Design System

## Visual direction
Premium dark-first builder tool, inspired by the clarity of Linear and Vercel without copying their interfaces. Light mode supported. Use clear focus states, restrained gradients, and high information density without clutter.

## Tokens
- Background: `#090D18`; surface: `#101727`; raised surface: `#141E31`.
- Text: `#F4F6FC`; muted: `#9BA8BD`; border: `rgba(185,201,231,.13)`.
- Accent violet: `#9B82FF`; mint: `#65E2D0`; amber: `#FFBD73`.
- Typography: Space Grotesk for headings, DM Sans for interface/body.
- Spacing: 4px base; common steps 8, 12, 16, 24, 32, 48, 64.
- Radius: 8px controls, 12px buttons, 16–20px cards, 24px feature panels.

## Components
Buttons (primary/quiet/outline), search input, filter chips, event cards, source/verification badges, countdown label, empty states, modal, toast, tabs, skeletons, tables, timeline, checklist.

## Motion/accessibility
150–220ms hover/focus transitions; reduced-motion support; keyboard-operable controls; visible focus; semantic landmarks; labels; contrast target WCAG 2.2 AA; do not communicate status by color alone. Verify all flows at 200% zoom and mobile widths.
