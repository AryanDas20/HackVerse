# Website tour and downloadable guide

- Start the in-app tour from the ✧ icon in the header or Settings → Replay website tour.
- The tour navigates through Home, Explore, Community, Smart Team Builder, Messages, Profile, Activity, Settings and Agent37 AI; each step scrolls to and highlights the relevant interface area.
- The guide file lives at `public/guide.html`. The home hero and footer include a **Download PDF guide** button. The PDF is also available at `public/HackVerse-Website-Guide.pdf`. Use **View illustrated guide** to open the standalone `public/guide.html` version offline or in a browser.
- The guide includes vector illustrations and illustrated interface mockups. They are explanatory previews, not screenshots captured from a live production account. No real user profile or chat data is embedded.
